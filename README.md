# BeyondResume AI

An AI-powered Authentic Capability Intelligence System for hiring.

## Overview
BeyondResume AI evaluates candidates based on their reasoning, problem‑solving abilities, and authentic project contributions rather than just résumé keywords.

- **Candidate experience**: Upload resume, take AI interview, receive capability scores.
- **Recruiter tools**: Post jobs, view ranked candidates, view detailed capability reports.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS v3 with custom design tokens
- **Animations**: Framer Motion v11
- **UI**: shadcn/ui, Lucide icons
- **State**: Zustand
- **Forms**: React Hook Form + Zod
- **Backend**: Node.js 20, Prisma, Supabase

## Getting Started
```bash
npm install
npm run dev
```
Open http://localhost:3000 to view the app.
